Assurance

      
Beta priors for the completion rates, given by a mean and an effective sample size; a normal prior for the completers’ difference in means (SD 0 fixes it at the planning value).

      

        
        
        
        
        
        
        
        
      

      

      

      

    

  


  
  

    
Simulation

    
Simulates trials analysed with the composite test in the Design panel (continuous efficacy, superiority), with dropout unrelated to the outcome. Checks the analytic power, or the type I error under the null hypothesis. The longitudinal dropout model of Appendix C, with MMRM and placebo-based multiple imputation as comparators, is in the R package (cs_simulate(dropout = "appendixC")).

    

      
      
      
      
    

    
 

    

    

    

  


  
  

    
MMRM comparator

    
Sample size for a mixed model for repeated measures, which estimates the effect had every patient stayed on treatment, assuming dropout is missing at random (the hypothetical strategy). It answers a different question from the composite, so its effect size is entered separately. Completion rates, α, power and allocation come from the Design panel.

About

    
compositeSS implements design and sample size methods for randomized trials in which dropout is part of the outcome, the composite strategy of the ICH E9(R1) addendum: the Shih–Quan composite test of completion and efficacy among completers, with unequal or estimand-aligned weights and an optional contingent rule; the expected benefit per randomized patient (θ) with its direct test; the standardized composite effect size ψ; and, as a comparator for a different estimand, the sample size of a mixed model for repeated measures.

    
This page is a JavaScript version of the calculator in the compositeSS R package, written and maintained by the package authors. It reproduces the package’s calculations step by step: sample sizes agree exactly and probabilities to at least six significant digits, as the validation page shows by recomputing the package’s own results in your browser. Monte Carlo results (assurance, simulation, bootstrap) use a different random number generator from R and so agree only up to simulation error.

    
What is only in the R package

    
The longitudinal dropout model of Appendix C, with MMRM and placebo-based multiple imputation as comparators; the worst-rank, win-odds and trimmed-mean analyses; the logistic-regression completion statistic; and assurance-based sample size. The package and the source of this page are in the same repository. Install the package in R with

    
remotes::install_github("jrabin18/compositeSS")
compositeSS::run_calculator()

    
Notation

    
A is the active treatment and B the comparator; pA, pB the probabilities of completing the trial on assigned treatment; μA, μB the mean improvements among completers and σ their SD; r = nB/nA. Z(d) compares completion and Z(e) efficacy among completers, both one-sided and oriented so that positive values favour A. The weighted Z is w(d)Z(d) + w(e)Z(e) with w(d)² + w(e)² = 1; Fisher’s method rejects when the product of the two one-sided P values is small.
